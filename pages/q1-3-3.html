先读整体，再逐行理解

INSERT ... SELECT 从MEMBERS选一个有赞助人的账号。本数据选到24000，沿24000→22086→18148→13943把费用归给Tuan Haddad，而不是归给直接赞助人22086。事件时间落在上半年范围，因此会影响该视图。

  1. L1INSERT INTO BOOKING_EVENTS

    向 BOOKING_EVENTS 新增事件；下一行明确目标列，后面的 SELECT 负责生成要插入的数据。未列出的 event_id 使用列默认序列值。

    Begin inserting a new event; omitted event_id uses its default.

  2. L2 (member_id, vehicle_id, event_type, event_time, amount)

    目标五列依次是收费成员、车辆、事件类型、事件时间、金额。INSERT…SELECT 后产生的五个值必须与此顺序一一对应。

    Declare the five target columns in the order supplied by SELECT.

  3. L3SELECT member_id,

    从后面筛出的 MEMBERS 行读取 member_id，作为新增损坏收费的所属成员。此 SELECT 是插入的数据源，不是独立展示查询。

    Start the source SELECT with the charged member ID.

  4. L4 'VEH-0001',

    第二个值是题目指定车辆字符串 VEH-0001，写入 vehicle_id。它和 Q4 使用的实验车辆无关，不应擅自改成 VEH-0004。

    Use the assignment-specified vehicle literal for the incident.

  5. L5 'Incident',

    第三个值 Incident 写入 event_type，表示事故或损坏收费。字符串要用单引号，不能把它写成未加引号的列名。

    Insert the Incident event-type string.

  6. L6 TIMESTAMP '2026-05-04 09:15:00',

    第四个值是明确类型的 TIMESTAMP，2026-05-04 09:15:00 位于 Q1.2 的半年计费区间内；这里不是数据库当前时间。

    Use the specified timestamp within the liability billing window.

  7. L7 90000.00

    第五个值 90000.00 写入 amount，即新增九万的费用。此行没有逗号，说明 SELECT 的五列值已全部列出。

    Supply the numeric damage charge as the final selected value.

  8. L8FROM MEMBERS

    从 MEMBERS 会员表选择收费对象；它不枚举事件表，后面的条件只确定一名被赞助会员。

    Choose the charged person from MEMBERS.

  9. L9WHERE sponsor_id IS NOT NULL

    只保留 sponsor_id 非 NULL 的会员，确保新增费用会经过赞助链归账。IS NOT NULL 是空值判断，不可替换成 != NULL。

    Restrict the candidate to a sponsored member.

  10. L10ORDER BY member_id DESC

    将合格会员按 member_id 从大到小排列，为 LIMIT 1 决定唯一对象；这不是按姓名或费用排名。

    Order sponsored candidates by descending member ID.

    最多取一个合格会员并结束 INSERT 整条语句，所以正常有候选人时新增一条事件；无候选人时不会插入任何行。

    Insert at most one selected event and terminate the statement.

聚合函数

SUM · 求和

SUM(numeric_expression)

输入组内数值，返回总和；输入numeric时返回numeric。忽略NULL。

本作业中的作用
Q1.2汇总最终根账号费用；Q2.1.3汇总三月Incident金额。
输入与输出示例
教学：10、NULL、20求和为30；不匹配任何行时SUM为NULL。
边界与常见错误
SUM(COALESCE(amount,0))会把已有行的NULL当0，但完全空的输入SUM仍为NULL。无GROUP BY的聚合仍输出一行。
相关题目：Q1.2 · Q1.3.1 · Q1.3.2 · Q1.3.3 · Q2.1.3
条件表达式

COALESCE · 首个非空值

COALESCE(value1, value2, ...)

从左到右返回首个非NULL值；全NULL则NULL。参数需能转换为公共类型。

本作业中的作用
原题Q1.2把COALESCE(sponsor_id,member_id)列为错误的一层替代方案；当前原代码使用SUM(e.amount)，没有COALESCE。
输入与输出示例
教学：COALESCE(NULL,0)=0；C赞助人B、B赞助人A时COALESCE只得到B，不得到A。
边界与常见错误
它不是循环、递归或普通函数调用求值模型；返回0不证明原始费用为0。
相关题目：Q1.2 · Q1.3.1 · Q1.3.3
关键字

ORDER BY / DESC / LIMIT / AS

ORDER BY collections DESC, station_id ASC LIMIT 1

排序键从左到右比较；默认ASC，DESC降序；LIMIT限制输出；AS给对象/列起名。

本作业中的作用
每类冠军、账户top10、最新事件、同值稳定次序。
输入与输出示例
教学：次数5/ID2与5/ID1，降序次数相同再ID升序，ID1先。
边界与常见错误
LIMIT无确定排序可能不稳定；视图或物化关系调用方需要保证显示顺序时显式ORDER BY。

DDL语句

MATERIALIZED VIEW / REFRESH · 保存与重算

CREATE MATERIALIZED VIEW name AS query; REFRESH MATERIALIZED VIEW name;

创建存查询结果；REFRESH重新计算并替换保存数据。

本作业中的作用
Q1.3保存top10，插入90000后展示陈旧，再刷新。
输入与输出示例
教学：物化100，底表120，刷新前读100，刷新后120。
边界与常见错误
换取读取省计算的代价是存储、维护、刷新时延/开销。原脚本未用CONCURRENTLY，不宣称并发刷新。

TIMESTAMP / INTERVAL / 半开区间

TIMESTAMP文字解析时间值；INTERVAL是时间长度；>=下界且<下一周期起点表示完整周期。

INSERT ... SELECT / VALUES / UPDATE ... RETURNING

Explanation 
The supplied INSERT chooses member 24000. Its sponsorship chain is 24000 -> 22086 -> 
18148 -> 13943, so the additional 90,000.00 is billed to Tuan Haddad (13943). Query A 
immediately puts that account first at 90,673.75. Query B still shows the earlier top ten, led 
by Ana Lopez, and does not include Tuan Haddad. After REFRESH, Query B shows the 
same updated ten rows as Query A; account 397 drops out of the top ten. 
A materialized view trades faster reads for extra storage, refresh work and potentially stale 
answers between refreshes. An ordinary view computes an answer from the data visible to 
each query.
