聚合函数

SUM · 求和

SUM(numeric_expression)

输入组内数值，返回总和；输入numeric时返回numeric。忽略NULL。

本作业中的作用
Q1.2汇总最终根账号费用；Q2.1.3汇总三月Incident金额。
输入与输出示例
教学：10、NULL、20求和为30；不匹配任何行时SUM为NULL。
边界与常见错误
SUM(COALESCE(amount,0))会把已有行的NULL当0，但完全空的输入SUM仍为NULL。无GROUP BY的聚合仍输出一行。
相关题目：Q1.2 · Q1.3.1 · Q1.3.2 · Q1.3.3 · Q2.1.3
关键字/集合运算

WITH RECURSIVE / UNION ALL · 逐层扩展

WITH RECURSIVE tree AS (seed UNION ALL recursive_term) SELECT ...;

先运行非递归seed，再反复用上轮结果求下一轮，直到无新行；UNION ALL保留重复。

本作业中的作用
根会员先映射自己，子会员继承根account_id。
输入与输出示例
教学：1无赞助人，2→1，3→2；各轮得到1→1、2→1、3→1。
边界与常见错误
自引用外键不防环。当前向下算法从根出发，孤立环不会被访问；一般递归若无终止/循环检测可能不断扩展。
相关题目：Q1.2 · Q1.3.1 · Q1.3.2
DDL语句

VIEW · 普通视图

CREATE VIEW name AS query;

保存查询定义，读取时基于当次可见数据执行规划。

本作业中的作用
V_BUSIEST_BAYS、V_ACCOUNT_LIABILITY封装可重复调用的逻辑。
输入与输出示例
教学：底表费用从100变120后，再查普通视图看到符合快照的新总额120。
边界与常见错误
不会自动保存结果；创建成功不证明定义逻辑符合题目。同名CREATE通常报已存在。
相关题目：Q1.1.1 · Q1.1.2 · Q1.2 · Q1.3.2 · Q2.1.2
DDL语句

MATERIALIZED VIEW / REFRESH · 保存与重算

CREATE MATERIALIZED VIEW name AS query; REFRESH MATERIALIZED VIEW name;

创建存查询结果；REFRESH重新计算并替换保存数据。

本作业中的作用
Q1.3保存top10，插入90000后展示陈旧，再刷新。
输入与输出示例
教学：物化100，底表120，刷新前读100，刷新后120。
边界与常见错误
换取读取省计算的代价是存储、维护、刷新时延/开销。原脚本未用CONCURRENTLY，不宣称并发刷新。
相关题目：Q1.3.1 · Q1.3.2 · Q1.3.3
语句与选项

EXPLAIN / ANALYZE / BUFFERS · 观察真实工作

EXPLAIN (ANALYZE, BUFFERS) SELECT ...;

EXPLAIN只显示规划；加ANALYZE实际执行并给出测量；BUFFERS显示缓冲访问。

本作业中的作用
本作业比较计划成本、估计/实际行数、耗时与页访问。
输入与输出示例
教学：cost=0..10 rows=2，actual time=0.1..0.2 rows=6 loops=1，表示估2实6，成本不是0.2毫秒。
边界与常见错误
EXPLAIN ANALYZE会真的执行语句；用于修改语句时也会产生修改。BUFFERS父节点通常包含子节点，不重复求和。
相关题目：Q1.1.2 · Q1.3.2 · Q2.1.2 · Q2.1.3 · Q2.2.2 · Q2.2.5 · Q3.1.2 · Q3.2
执行计划字段

cost / rows / width / loops / time

cost=startup..total rows=estimate width=bytes; actual time=first..last rows=actual loops=n

cost为规划成本单位；width为估计平均输出字节；actual time单位ms，rows/time多循环时按每循环平均给出。

本作业中的作用
原生Q1.1扫描29769.5×2=59539条Collect；顶层估2实6。
输入与输出示例
教学：rows=100 loops=3表示平均每轮100行，总约300，不是总100。
边界与常见错误
父节点时间包含其子树部分工作，不能把所有层时间相加。并行worker与总墙钟时间需结合完整计划。
