The co-operative wants to know which e-mail providers its members use, so that it can investigate why its newsletter is being rejected by some of them. The provider domain is the part of the e-mail address after the @ character. Members have entered their addresses inconsistently, so domains must be compared case-insensitively — Bigpond.com and bigpond.com are the same provider.

(1) Write an expression that identifies each member's e-mail provider domain, and use it to report each distinct domain together with the number of members who use it, most popular first. You may use string processing functions, including the regex functions. (1 mark)

06

先读整体，再逐行理解

SPLIT_PART(email,'@',2)按分隔符@切开，字段号从1开始，取第二段；LOWER再小写化。教学例：a@Bigpond.com→Bigpond.com→bigpond.com；b@bigpond.com→同一个键，所以合计2。

  1. L1-- Extract provider domains, fold case, and count members per domain.

    注释概括域名提取、小写规范化和按域名统计会员三个阶段；不执行任何数据转换。

    Source comment: Extract provider domains, fold case, and count members per domain.

  2. L2SELECT LOWER(SPLIT_PART(email, '@', 2)) AS provider_domain,

    SPLIT_PART(email, '@', 2) 取 @ 分隔后的第二段，再由 LOWER 统一小写；provider_domain 是输出列名。本数据使用正常的单 @ 邮箱，表达式不负责校验任意格式的邮箱。

    Extract the second @-separated field and normalize it with LOWER, naming it provider_domain. This assumes the dataset’s normal single-@ addresses; it is not an email validator.

  3. L3 COUNT(*) AS member_count

    COUNT(*) 数每个规范化域名下的成员行，输出名为 member_count。每位成员一行，即使 local part 不同，只要域名相同也会进入同一组。

    COUNT(*) counts member rows per normalized domain as member_count. Different address prefixes still contribute to the same domain group.

  4. L4FROM MEMBERS

    从 MEMBERS 读全部成员。这里没有稀有域名 WHERE，因为问题要求统计所有不同 provider，而不只某一家。

    Read every member from MEMBERS. There is no rare-domain WHERE because the question asks for all providers.

  5. L5GROUP BY LOWER(SPLIT_PART(email, '@', 2))

    按同一个 LOWER(SPLIT_PART(...)) 表达式分组。若只在 SELECT 中 LOWER、分组却用原字符串，大小写变体仍可能先被拆成不同组。

    Group by exactly the same normalized expression. Normalizing only the displayed SELECT value would not correctly merge groups formed from differently cased raw strings.

  6. L6ORDER BY member_count DESC, provider_domain;

    按 member_count 降序把最常用域名排前；同人数按域名升序。最终 12 组共覆盖 24,000 人；索引按域名排序也不能直接提供按人数排序。

    Sort counts descending and domain names ascending for ties. Twelve groups cover 24,000 members; domain index order does not directly order aggregate counts.

聚合函数

COUNT · 计数

COUNT(*) / COUNT(expression)

输入一组行，返回bigint计数；*计所有行，expression只计表达式非NULL行。

本作业中的作用
Q1.1统计每类车每站的Collect事件；Q2.2统计每个域名会员。
输入与输出示例
教学：amount为10、NULL、20时，COUNT(*)=3，COUNT(amount)=2。
边界与常见错误
空输入COUNT返回0。COUNT(DISTINCT vehicle_id)会变成不同车辆数，不能代替取车次数。
相关题目：Q1.1.1 · Q1.1.2 · Q2.1.3 · Q2.2.1 · Q2.2.2 · Q2.2.5
字符串函数

LOWER · 转小写

LOWER(text) → text

输入文字，按适用排序/字符规则返回小写文字；NULL输入返回NULL。

本作业中的作用
规范化域名，使Bigpond.com与bigpond.com归入同组和同索引键。
输入与输出示例
教学：LOWER('Bigpond.com')='bigpond.com'。
边界与常见错误
它不验证邮箱格式，不去空格，也不自动修复拼写；与Unicode/locale有关的生产需求须另外设计。
相关题目：Q2.2.1 · Q2.2.2 · Q2.2.3 · Q2.2.4 · Q2.2.5
字符串函数

SPLIT_PART · 按分隔符取段

SPLIT_PART(email, '@', 2) → text

三个参数：原文本、分隔文本、从1起的段号。返回所选段。

本作业中的作用
取每位会员邮箱@之后第二段，外包LOWER得到规范化域名。
输入与输出示例
教学：SPLIT_PART('a@X.com','@',2)='X.com'。
边界与常见错误
无@则第二段为空字符串；多@只取第2段；参数NULL则返回NULL。NOT NULL UNIQUE不保证邮箱合法。
相关题目：Q2.2.1 · Q2.2.2 · Q2.2.4 · Q2.2.5
特殊值与谓词

NULL / IS NULL / 三值逻辑

x IS NULL; x IS NOT NULL

NULL表示缺失或未知；普通比较产生unknown，不等同于空字符串或0。

本作业中的作用
无sponsor是根账号；未匹配外连接右侧是NULL；非收费事件amount为空。
输入与输出示例
教学：NULL=NULL不是true，筛空必须IS NULL；WHERE仅保留true。
边界与常见错误
COUNT(*)包含NULL行，COUNT(col)不计空值。SUM忽略空值。NOT NULL仅限制缺失，不限制字段业务合法性。
相关题目：Q1.2 · Q2.2.1 · Q3.1.1 · Q4.1.3
关键字

GROUP BY / WHERE / HAVING · 逻辑阶段

FROM/JOIN → WHERE → GROUP BY/aggregate → HAVING → window → SELECT → ORDER BY → LIMIT

WHERE先筛输入行；GROUP BY把相同键行合组；HAVING筛聚合组；窗口在分组后处理已有行。

本作业中的作用
先筛Collect再数每站次数；窗口rn须外层过滤。
输入与输出示例
教学：筛掉Return后3条Collect归一组COUNT=3，不能把所有事件先数完再显示Collect。
边界与常见错误
这是逻辑解释顺序，不是强制物理执行顺序。HAVING未在原答案使用，列出是帮助理解阶段差异。
相关题目：Q1.1.1 · Q1.2 · Q2.2.1
符号与运算符

引号 / 点号 / 括号 / ; / :: / <> / *

e.vehicle_id; 'Collect'; amount::numeric; a <> b

单引号为字符串，点号为对象/别名字段，分号终结SQL；::类型转换，<>不等，*可为所有列或COUNT行数语法。

本作业中的作用
原代码的字符串Collect、别名e/v、函数嵌套括号、EXPLAIN转录中的::text。
输入与输出示例
教学：event_type='Collect'比较列与文字；"Collect"会当区分大小写的标识符，含义不同。
边界与常见错误
括号可能是函数参数、子查询、CTE或索引表达式，按上下文判断。AND/OR遇NULL使用三值逻辑；注释--直到行末不执行。

LOWER必须在分组前吗？

展开参考答案

展开参考答案
