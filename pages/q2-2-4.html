06

先读整体，再逐行理解

CREATE INDEX ... ON MEMBERS ((...)) 把表达式包为索引键。额外括号用于表达式索引语法，不是又调用一层函数。插入/修改email时需要重新计算并维护键，所以读取收益伴随写入和存储代价。

  1. L1-- Index the same normalized domain expression used in the queries.

    注释提醒索引表达式应与查询的规范域名表达式一致；索引完整 email 不能直接替代它。

    Source comment: Index the same normalized domain expression used in the queries.

  2. L2CREATE INDEX IDX_MEMBER_DOMAIN

    创建函数/表达式索引 IDX_MEMBER_DOMAIN。它保存计算出来的域名键，区别于已有 email UNIQUE 索引保存完整邮箱。

    Create expression index IDX_MEMBER_DOMAIN, whose keys are computed domains rather than complete email addresses.

  3. L3ON MEMBERS (LOWER(SPLIT_PART(email, '@', 2)));

    对 MEMBERS 的 LOWER(SPLIT_PART(email, '@', 2)) 建索引，表达式要与查询一致。双层括号区分索引列列表与表达式；此处不会新增一个实体 provider_domain 列。

    Index the matching normalized-domain expression on MEMBERS. Parentheses delimit the index key expression; this does not add a stored provider_domain column.

07

特殊函数、语法与符号

先区分函数、关键字、运算符和语句；下面的输入输出例子均是教学示例，未在网页连接数据库执行。

字符串函数

LOWER · 转小写

LOWER(text) → text

输入文字，按适用排序/字符规则返回小写文字；NULL输入返回NULL。

本作业中的作用
规范化域名，使Bigpond.com与bigpond.com归入同组和同索引键。
输入与输出示例
教学：LOWER('Bigpond.com')='bigpond.com'。
边界与常见错误
它不验证邮箱格式，不去空格，也不自动修复拼写；与Unicode/locale有关的生产需求须另外设计。
相关题目：Q2.2.1 · Q2.2.2 · Q2.2.3 · Q2.2.4 · Q2.2.5
字符串函数

SPLIT_PART · 按分隔符取段

SPLIT_PART(email, '@', 2) → text

三个参数：原文本、分隔文本、从1起的段号。返回所选段。

本作业中的作用
取每位会员邮箱@之后第二段，外包LOWER得到规范化域名。
输入与输出示例
教学：SPLIT_PART('a@X.com','@',2)='X.com'。
边界与常见错误
无@则第二段为空字符串；多@只取第2段；参数NULL则返回NULL。NOT NULL UNIQUE不保证邮箱合法。
相关题目：Q2.2.1 · Q2.2.2 · Q2.2.4 · Q2.2.5
DDL语法

Expression index · 表达式索引

CREATE INDEX IDX_MEMBER_DOMAIN ON MEMBERS ((LOWER(SPLIT_PART(email,'@',2))));

以计算结果而非原列作为索引键；写入时维护，查询语义表达式要与键相匹配。

本作业中的作用
从完整email索引转为规范化域名键，支持稀有域名查找。
输入与输出示例
教学：a@X.COM与b@x.com索引键同为x.com。
边界与常见错误
不是每个含表达式的聚合都加速；全体人数统计仍要读全体。函数须符合不可变性等索引条件。
相关题目：Q2.2.3 · Q2.2.4 · Q2.2.5

09

从要求推到结论

CREATE INDEX ... ON MEMBERS ((...)) 把表达式包为索引键。额外括号用于表达式索引语法，不是又调用一层函数。插入/修改email时需要重新计算并维护键，所以读取收益伴随写入和存储代价。

教学例：a@X.COM保存键x.com；查WHERE LOWER(SPLIT_PART(email,'@',2))='x.com'可定位。若只写SPLIT_PART而去掉LOWER，语义不同，不能假定原索引能直接服务相同查找。

题目条件→表与关系→代码步骤→可见证据→有边界的结论
原答案核对 / 常见误区 / 边界

表达式索引使用的函数须满足索引表达式所要求的不可变性等条件。LOWER/SPLIT_PART的该用法可以建立，不应泛化到NOW()等随时间变化的函数。
