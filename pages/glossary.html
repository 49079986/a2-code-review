聚合函数

COUNT · 计数

COUNT(*) / COUNT(expression)

输入一组行，返回bigint计数；*计所有行，expression只计表达式非NULL行。

本作业中的作用
Q1.1统计每类车每站的Collect事件；Q2.2统计每个域名会员。
输入与输出示例
教学：amount为10、NULL、20时，COUNT(*)=3，COUNT(amount)=2。
边界与常见错误
空输入COUNT返回0。COUNT(DISTINCT vehicle_id)会变成不同车辆数，不能代替取车次数。
相关题目：Q1.1.1 · Q1.1.2 · Q2.1.3 · Q2.2.1 · Q2.2.2 · Q2.2.5
聚合函数

SUM · 求和

SUM(numeric_expression)

输入组内数值，返回总和；输入numeric时返回numeric。忽略NULL。

本作业中的作用
Q1.2汇总最终根账号费用；Q2.1.3汇总三月Incident金额。
输入与输出示例
教学：10、NULL、20求和为30；不匹配任何行时SUM为NULL。
边界与常见错误
SUM(COALESCE(amount,0))会把已有行的NULL当0，但完全空的输入SUM仍为NULL。无GROUP BY的聚合仍输出一行。
相关题目：Q1.2 · Q1.3.1 · Q1.3.2 · Q1.3.3 · Q2.1.3
条件表达式

COALESCE · 首个非空值

COALESCE(value1, value2, ...)

从左到右返回首个非NULL值；全NULL则NULL。参数需能转换为公共类型。

本作业中的作用
原题Q1.2把COALESCE(sponsor_id,member_id)列为错误的一层替代方案；当前原代码使用SUM(e.amount)，没有COALESCE。
输入与输出示例
教学：COALESCE(NULL,0)=0；C赞助人B、B赞助人A时COALESCE只得到B，不得到A。
边界与常见错误
它不是循环、递归或普通函数调用求值模型；返回0不证明原始费用为0。
相关题目：Q1.2 · Q1.3.1 · Q1.3.3
窗口函数

ROW_NUMBER · 窗口行号

ROW_NUMBER() OVER (PARTITION BY body_type ORDER BY collections DESC, station_id)

无普通参数；按窗口顺序返回从1开始的bigint，每个分区重新编号。

本作业中的作用

输入与输出示例
教学：Sedan/S1/5、Sedan/S2/5，加station_id排序后rn分别1、2。

不加稳定次序时并列胜者不确定；它不会像GROUP BY一样减少行数，要外层WHERE rn=1。

LOWER(text) → text

SPLIT_PART(email, '@', 2) → text

本作业中的作用

关键字/查询结构

WITH / CTE · 给中间查询命名

WITH counts AS (SELECT ...) SELECT ... FROM counts;

命名结果仅对当前SQL可见，便于把计算分阶段。不是创建永久表，也不必然物化。

本作业中的作用
Q1把计数与排名分开；Q4给最新事件中间结果命名。
输入与输出示例
教学：WITH x AS (SELECT 2 AS n) SELECT n+1 FROM x; 返回3。
边界与常见错误
多个CTE用逗号隔开；CTE结束后的外层SELECT仍属于同一条语句。优化器可内联，不要用书写结构猜扫描次数。
相关题目：Q1.1.1 · Q1.2 · Q1.3.1 · Q4.1.1
关键字/集合运算

WITH RECURSIVE / UNION ALL · 逐层扩展

WITH RECURSIVE tree AS (seed UNION ALL recursive_term) SELECT ...;

先运行非递归seed，再反复用上轮结果求下一轮，直到无新行；UNION ALL保留重复。

本作业中的作用
根会员先映射自己，子会员继承根account_id。
输入与输出示例
教学：1无赞助人，2→1，3→2；各轮得到1→1、2→1、3→1。
边界与常见错误
自引用外键不防环。当前向下算法从根出发，孤立环不会被访问；一般递归若无终止/循环检测可能不断扩展。
相关题目：Q1.2 · Q1.3.1 · Q1.3.2
关键字

JOIN / ON / 别名 · 补齐关联属性

FROM BOOKING_EVENTS e JOIN VEHICLES v ON v.vehicle_id=e.vehicle_id

内连接保留符合ON的行对；e/v是查询局部别名，点号取对应表列。

本作业中的作用
事件没有body_type和station_name，必须经车辆到车型和站点。
输入与输出示例
教学：事件(V1,Collect)与车辆(V1,MD1,S1)连接后才知道车型和站点ID。
边界与常见错误
目标主键唯一避免此连接成倍放大事件。漏写连接条件会形成笛卡尔积；同名列要写别名前缀。
相关题目：Q1.1.1 · Q1.2 · Q3.1.1
关键字

LEFT JOIN / NULL 扩展

VEHICLES v LEFT JOIN BOOKING_EVENTS e ON ... WHERE e.vehicle_id IS NULL

左边每辆车至少保留；右边无匹配时填NULL。

本作业中的作用
Q3只让Collect参与匹配，再保留完全没Collect的车辆。
输入与输出示例
教学：V2只有Reserve，ON中限定Collect后无匹配，所以e.vehicle_id为NULL，V2被保留。
边界与常见错误
把e.event_type=Collect放WHERE会剔掉NULL行，破坏反连接。需选真实匹配时保证非空的列做IS NULL。
相关题目：Q3.1.1 · Q3.1.2
谓词

EXISTS / NOT EXISTS · 存在性判断

WHERE NOT EXISTS (SELECT 1 FROM BOOKING_EVENTS e WHERE e.vehicle_id=v.vehicle_id AND ...)

子查询至少有一行则EXISTS为true；NOT EXISTS反转。子查询投影值通常与存在性无关。

本作业中的作用
为每辆车确认不存在任何Collect事件。
输入与输出示例
教学：子查询返回NULL一行时EXISTS仍true，因为检查有无行而不是行值。
边界与常见错误
NOT IN与含NULL集合会有三值逻辑陷阱；相关子查询逻辑不强制物理重复全扫描，规划器可去相关。
相关题目：Q3.1.1 · Q3.1.2
特殊值与谓词

NULL / IS NULL / 三值逻辑

x IS NULL; x IS NOT NULL

NULL表示缺失或未知；普通比较产生unknown，不等同于空字符串或0。

本作业中的作用
无sponsor是根账号；未匹配外连接右侧是NULL；非收费事件amount为空。
输入与输出示例
教学：NULL=NULL不是true，筛空必须IS NULL；WHERE仅保留true。
边界与常见错误
COUNT(*)包含NULL行，COUNT(col)不计空值。SUM忽略空值。NOT NULL仅限制缺失，不限制字段业务合法性。
相关题目：Q1.2 · Q2.2.1 · Q3.1.1 · Q4.1.3
关键字

GROUP BY / WHERE / HAVING · 逻辑阶段

FROM/JOIN → WHERE → GROUP BY/aggregate → HAVING → window → SELECT → ORDER BY → LIMIT

WHERE先筛输入行；GROUP BY把相同键行合组；HAVING筛聚合组；窗口在分组后处理已有行。

本作业中的作用
先筛Collect再数每站次数；窗口rn须外层过滤。
输入与输出示例
教学：筛掉Return后3条Collect归一组COUNT=3，不能把所有事件先数完再显示Collect。
边界与常见错误
这是逻辑解释顺序，不是强制物理执行顺序。HAVING未在原答案使用，列出是帮助理解阶段差异。
相关题目：Q1.1.1 · Q1.2 · Q2.2.1
关键字

ORDER BY / DESC / LIMIT / AS

ORDER BY collections DESC, station_id ASC LIMIT 1

排序键从左到右比较；默认ASC，DESC降序；LIMIT限制输出；AS给对象/列起名。

本作业中的作用
每类冠军、账户top10、最新事件、同值稳定次序。
输入与输出示例
教学：次数5/ID2与5/ID1，降序次数相同再ID升序，ID1先。
边界与常见错误
LIMIT无确定排序可能不稳定；视图或物化关系调用方需要保证显示顺序时显式ORDER BY。
相关题目：Q1.1.1 · Q1.2 · Q1.3.3 · Q4.1.1
PostgreSQL查询语法

DISTINCT ON · 每组保留首行

SELECT DISTINCT ON (vehicle_id) ... ORDER BY vehicle_id, event_time DESC, event_id DESC

每个vehicle_id只留排序后的第一行；ORDER BY最左表达式须对应DISTINCT ON。

本作业中的作用
当前根Q4.1.1取每辆车最新事件，外层再筛Return。
输入与输出示例
教学：同车09:00 Return、10:00 Reserve保留10:00 Reserve。
边界与常见错误
先筛Return会回答另一个问题。没有time/ID稳定排序时“第一行”不确定；其他数据库未必支持此扩展。

VIEW · 普通视图

V_BUSIEST_BAYS、V_ACCOUNT_LIABILITY封装可重复调用的逻辑。

DDL语句

MATERIALIZED VIEW / REFRESH · 保存与重算

CREATE MATERIALIZED VIEW name AS query; REFRESH MATERIALIZED VIEW name;

创建存查询结果；REFRESH重新计算并替换保存数据。

本作业中的作用
Q1.3保存top10，插入90000后展示陈旧，再刷新。

教学：物化100，底表120，刷新前读100，刷新后120。

换取读取省计算的代价是存储、维护、刷新时延/开销。原脚本未用CONCURRENTLY，不宣称并发刷新。

建立额外的有序键结构帮助定位记录，默认方法为B-tree。

教学：先Incident后Return，每种内部时间升序，如按姓再按名的电话簿。

索引增加存储和写入维护；不保证采用。索引列不含amount/vehicle_id，所以某些查询必须回heap。

DDL语法

Expression index · 表达式索引

CREATE INDEX IDX_MEMBER_DOMAIN ON MEMBERS ((LOWER(SPLIT_PART(email,'@',2))));

以计算结果而非原列作为索引键；写入时维护，查询语义表达式要与键相匹配。

本作业中的作用
从完整email索引转为规范化域名键，支持稀有域名查找。
输入与输出示例
教学：a@X.COM与b@x.com索引键同为x.com。
边界与常见错误
不是每个含表达式的聚合都加速；全体人数统计仍要读全体。函数须符合不可变性等索引条件。
相关题目：Q2.2.3 · Q2.2.4 · Q2.2.5
语句与选项

EXPLAIN / ANALYZE / BUFFERS · 观察真实工作

EXPLAIN (ANALYZE, BUFFERS) SELECT ...;

EXPLAIN只显示规划；加ANALYZE实际执行并给出测量；BUFFERS显示缓冲访问。

本作业中的作用
本作业比较计划成本、估计/实际行数、耗时与页访问。
输入与输出示例
教学：cost=0..10 rows=2，actual time=0.1..0.2 rows=6 loops=1，表示估2实6，成本不是0.2毫秒。
边界与常见错误
EXPLAIN ANALYZE会真的执行语句；用于修改语句时也会产生修改。BUFFERS父节点通常包含子节点，不重复求和。
相关题目：Q1.1.2 · Q1.3.2 · Q2.1.2 · Q2.1.3 · Q2.2.2 · Q2.2.5 · Q3.1.2 · Q3.2
执行计划字段

cost / rows / width / loops / time

cost=startup..total rows=estimate width=bytes; actual time=first..last rows=actual loops=n

cost为规划成本单位；width为估计平均输出字节；actual time单位ms，rows/time多循环时按每循环平均给出。

本作业中的作用
原生Q1.1扫描29769.5×2=59539条Collect；顶层估2实6。
输入与输出示例
教学：rows=100 loops=3表示平均每轮100行，总约300，不是总100。
边界与常见错误
父节点时间包含其子树部分工作，不能把所有层时间相加。并行worker与总墙钟时间需结合完整计划。
相关题目：Q1.1.2 · Q1.3.2 · Q3.1.2 · Q3.2
执行统计

Buffers / heap blocks / hit / read

Buffers: shared hit=n read=m; Heap Blocks: exact=k

hit在PostgreSQL共享缓冲中找到；read需把页读入共享缓冲，仍可能由操作系统缓存服务；exact位图保留精确行位置。

本作业中的作用
Q3.2区分C1读31页与C2全hit；D2读全部1636heap块还读索引。
输入与输出示例
教学：shared hit=1659不一定是1659个唯一物理页，可能包含重访和子节点。
边界与常见错误
read不保证真正磁盘IO；不要把行选择率当页覆盖率。lossy若出现需重查整页，但本六图heap均报告exact。
相关题目：Q2.1.3 · Q2.2.5 · Q3.2
物理执行节点

Seq / Index / Bitmap / Index Only Scan

Seq Scan; Bitmap Index Scan → Bitmap Heap Scan

Seq逐页检查表；Index从键定位再取行；Bitmap先收位置再按heap页取；Index Only要求足够列与可见性条件。

本作业中的作用
全时段Collect可顺扫，少量Incident适合bitmap；稀有域名仍回heap取姓名。
输入与输出示例
教学：1000行取3行可定位，取950行常顺读省额外索引工作。
边界与常见错误
少量行可能散在很多页；Index Only也可能有Heap Fetches。不能只看“有索引”推断计划。
相关题目：Q2.1.2 · Q2.1.3 · Q2.2.5 · Q3.2
物理执行节点

Hash Join / Anti Join / Aggregate / Sort / WindowAgg

input scans → joins → aggregation → sorting/window

Hash Join按键建立哈希匹配；Anti Join保留无匹配；Aggregate把行变组；Sort排序；WindowAgg计算窗口。

本作业中的作用
Q1为事件补车型站点并排名；Q3反连接保留从未Collect的车。
输入与输出示例
教学：3事件连唯一车辆仍3行，按站计数可能成2组，窗口仍2行，外层rn=1才减少。
边界与常见错误
节点方向Right不改变目标语义；Batches/Sort Method等信息决定是否溢盘，不能凭cost猜。
相关题目：Q1.1.2 · Q2.2.2 · Q3.1.2
命令/配置参数

SET / SHOW / enable_* · 会话配置

SET enable_seqscan = off; SHOW transaction_isolation;

SET改变当前连接后续配置，SHOW读取。enable_indexscan/indexonlyscan/bitmapscan/seqscan是不同开关。

本作业中的作用
Q3.2三种设置组最后全部恢复on；Q4 SHOW确认默认隔离。
输入与输出示例
教学：只SET enable_indexscan=off时bitmap仍可能运行，所以索引抑制组需关三种。
边界与常见错误
off通常是抑制而非绝对无法使用；同文件需在同会话运行。配置不是SQL函数，也不修改表数据。

类型及运算

TIMESTAMP / INTERVAL / 半开区间

TIMESTAMP '2026-03-01'; NOW()+INTERVAL '3 days'

TIMESTAMP文字解析时间值；INTERVAL是时间长度；>=下界且<下一周期起点表示完整周期。

本作业中的作用
Q1上半年、Q2三月；Q4三天后预约。
输入与输出示例
教学：[3月1日00:00,4月1日00:00)包含3月31日深夜。
边界与常见错误
event_time无时区，NOW有时区，赋值受会话TimeZone影响。日期文字不含时间时为00:00。

事务控制语句

BEGIN / COMMIT / ROLLBACK / SAVEPOINT

BEGIN; SAVEPOINT s; ... COMMIT; / ROLLBACK TO s;

BEGIN开启事务；COMMIT成功则持久化；ROLLBACK撤销；SAVEPOINT标记局部可恢复点。

本作业中的作用
Q4保持两事务重叠，异常后COMMIT实际返回ROLLBACK。
输入与输出示例
教学：第一UPDATE成功、第二死锁，受害事务第一次更新也被撤销。
边界与常见错误
SAVEPOINT本身不自动恢复；需ROLLBACK TO。函数体BEGIN...END是语言代码块，不是独立事务。
相关题目：Q4.1.1 · Q4.1.3 · Q4.2.1
隔离级别与可见性

READ COMMITTED / snapshot · 读已提交快照

SHOW transaction_isolation;

默认READ COMMITTED每条命令看到该命令快照允许的已提交内容和自身可见修改。

本作业中的作用
T1先见Return，T2提交后T1后续Collect触发器见Reserve。
输入与输出示例
教学：两条SELECT之间别人提交更新，第二条可以读到不同值。
边界与常见错误
事务打开不固定首次快照；快照不是预留锁。普通SELECT仍取得兼容表锁，原题“无锁”是简化。
相关题目：Q4.1.1 · Q4.1.2 · Q4.1.3 · Q4.1.4
触发器与PL/pgSQL

BI_COLLECT / NEW / RAISE EXCEPTION

BEFORE INSERT ... FOR EACH ROW EXECUTE FUNCTION UDF_BI_COLLECT();

每个插入候选行之前调用函数；NEW是拟插入记录；RETURN NEW允许继续，RAISE EXCEPTION拒绝并抛错。

本作业中的作用
Collect时读该车按时间/ID最新事件，检查Incident、Collect或其他会员Reserve。
输入与输出示例
教学：last_type=Reserve且last_member=2、NEW.member_id=1时抛Vehicle ... reserved。
边界与常见错误
Reserve本身不进入Collect检查；最新未来事件也会当当前状态。NEW还不是已提交表行；触发器没有独立事务。

DML语句

INSERT ... SELECT / VALUES / UPDATE ... RETURNING

INSERT INTO t(cols) SELECT ...; UPDATE ... RETURNING vehicle_id,odometer;

INSERT SELECT把查询结果作为新行；VALUES写字面行；RETURNING输出本语句改变的行字段。

本作业中的作用
Q1.3选最大有赞助会员插入；Q4显示Reserve/里程修改值。
输入与输出示例
教学：149100+10 RETURNING149110，但BEGIN未提交时他人尚不能视为已提交。
边界与常见错误
UPDATE没WHERE可能改全表；RETURNING成功不是COMMIT成功。INSERT列顺序必须与SELECT/VALUES一一对应。

并发概念

Row lock / deadlock / wait-for graph · 行锁、死锁与等待图

T1 → T2 means T1 waits for T2

UPDATE持冲突行锁直到事务结束；等待环使所有参与者无法前进，数据库中止受害事务打破环。

本作业中的作用
T1持0401等0501，T2持0501等0401；本轮T2回滚、T1提交。
输入与输出示例
教学：只有T1→T2是等待；再出现T2→T1才成环。
边界与常见错误
按一致ID顺序预防，代价为重叠资源排队。受害PID会变化，不能把旧轮次结论套本轮图。

客户端显示

psql提示符与命令状态

assignment2=# / assignment2=*# / assignment2=!#

典型提示符中数据库名标识连接；*表示事务内，!表示事务失败；#常指当前角色具有超级用户权限，非所有环境都相同。

本作业中的作用
Q4用事务状态辨认未提交或失败；COMMIT后看实际返回COMMIT还是ROLLBACK。
输入与输出示例
教学：UPDATE 1只说修改一行，INSERT 0 1表示插入一行；它们不代表事务已提交。没有新提示符可能表示语句仍在等待。

括号/短横线等提示符可能表示输入尚未结束；仅凭等待画面不能证明死锁，需互相等待与错误证据。

psql客户端元命令

\if / \else / \endif / \r / \echo · 截图辅助命令

\if :{?a2_left} -- guarded commands \else \echo Wrong window \endif

截图中的条件块用于检查psql变量是否存在，选择运行/跳过的分支；\r清空当前查询缓冲，\echo输出提示。

本作业中的作用
用于原生实验防止向错误窗口发送命令；根提交SQL已整理为按连接标签执行的清单，不逐字包含所有交互辅助命令。
输入与输出示例
教学：:{?a2_left}检查变量是否被定义，不是SQL参数；\r只清空未发送语句，不回滚数据库事务。
边界与常见错误
跳过的分支可能在提示符出现@；不要把\endif当COMMIT，或把\r当ROLLBACK。以截图和当前SQL分别核对。
